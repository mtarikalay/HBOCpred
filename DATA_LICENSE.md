# Data and annotation redistribution notice

The MIT Licence applies to repository source code only.

The deposited processed feature matrix contains annotations derived from public
variant resources and third-party in silico predictors. Before making the
repository public, each predictor and source-data licence must be checked for
redistribution conditions. When direct redistribution is not permitted, retain
variant identifiers, a feature manifest and a regeneration script rather than
the restricted annotation column.

No patient-level clinical data should be committed. Any hospital audit table
must be de-identified, variant-level only, approved for release under the
relevant ethics/governance framework, and separated from the public ClinVar and
gnomAD-derived matrices.
