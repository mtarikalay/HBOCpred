# Executed analysis protocol and deviations

This describes what was actually run on 2026-09-05. It is not a prospectively registered protocol.

The primary source archive is kept at 2,160 records so historical inclusion discrepancies remain visible. Labels are processed LP/LB source labels, separately accompanied by embedded ClinVar significance and review status. Current Ensembl annotation gives 2,120 same-gene-transcript missense records; these receive a separate five-fold refit and a matched prediction-subset comparison. No non-MANE variant is automatically treated as non-missense. Multi-nucleotide substitutions are retained where present.

Before outcome-dependent selection, deterministic numeric engineering yields 90 fields and semantic duplicate reduction yields 48 representatives. Primary analysis excludes Reliability_index. No application-based availability screen is applied. Each inner-training partition and outer-training partition separately removes candidates with >40% missingness or no observed variation, fits a median imputer and standard scaler, ranks candidates by four complementary criteria, and greedily prunes absolute Pearson correlations above 0.90 to at most 25 predictors. The original algorithm's mRMR and correlation-clustering claims are not repeated because this implementation uses neither.

The four fixed model families are SVM–RBF, L2 logistic regression, Extra Trees and HistGB. Six distinct configurations per family are evaluated in four inner folds. Mean raw-score AUROC, its sample SD and a deterministic parameter-string order select a configuration. Platt calibration is cross-fitted over inner OOF scores to develop each balanced-accuracy-maximising threshold. The final calibrator uses all inner OOF scores. Mean4 from inner cross-calibrated probabilities receives logistic meta-calibration to obtain S_MAC. Inner tuning and calibration reuse training labels; outer-test records do not enter fitting. Family membership and output descriptors are revision-stage choices informed by earlier work.

Five repeats of five-fold outer CV give 25 fitted assessment objects; 17 complete gene holdouts give 17 more. The first-repeat fold map is reused for Reliability_index inclusion, joint BayesDel addAF/AlphaMissense exclusion, and current-transcript missense restriction (15 fits). A distinct deployment model fits all 2,160 records. The total is 58.

Output completeness is assessed on observed selected-panel entries before imputation, in all contexts. Below 80%, all model outputs are suppressed. The resulting 114 incomplete source records per repeated-CV assessment are retained in source accounting and excluded from scored-performance denominators. All application records satisfy the deployment guard.

Sensitivity/specificity and related binary metrics use V >= 3 among evaluable records. Continuous metrics use S_MAC. First-repeat states provide a single-prediction-per-variant descriptive audit. Repeat SDs describe split stability. Wilson intervals describe selected source proportions; fixed-score bootstrap intervals in the supplement omit model-refit, gene-cluster and transport uncertainty. Neither kind of interval repairs reference-label dependence.

The current gnomAD exercise is an eligibility audit, not a prediction validation. Fifty candidates under the documented query/AF/AN/PASS criteria reduce to two outside the full training and unresolved archives; these are alternative-transcript missense records and unscored. The hospital list has no supplied row-level reference evidence. All 31 distinct in-scope missense variants from 47 source rows are listed in main Table 5 after allele and transcript identity checks: 22 anchor overlaps, eight application-catalogue overlaps and one other source-archive record. They are scored with the frozen deployment model; anchor-overlapping scores are in-sample, and no independent external performance is estimated. No earlier unverified external summary is included as a new result.

Compared with the supplied R2/R3 packages, the release changes feature-availability selection, inner preprocessing, Reliability_index handling, output terminology, evaluation completeness and reporting. It corrects the candidate-learner and software descriptions and replaces all numerical estimates with genuine refit results. Thus changes in numbers are not evidence that an unchanged old model has improved.
