# HBOCpred

Code and data for prioritising unresolved germline missense variants in 17 hereditary breast and ovarian cancer genes.

- **Data:** 2,160 reference variants, 43,679 unresolved variants, predictor matrices and recorded cross-validation assignments.
- **Python:** preprocessing, model fitting, scoring, analysis tables and figures.
- **R:** the Shiny catalogue viewer, using the same saved scores.
- **Model:** the frozen deployment ensemble and its calibration parameters.

The four learners produce V0–V4 vote counts. S_MAC adds a continuous ranking score. These outputs support research review and are separate from ACMG/AMP classifications.

## Run

Use Python 3.12 and the versions in `requirements.txt`.

```bash
python scripts/assemble_large_files.py
python -m pip install -r requirements.txt
python scripts/verify_repository.py
```

The first command restores one large compressed dataset from two parts and checks its original checksum.

To score an aligned predictor matrix:

```bash
python scripts/score_variants.py --input variants.csv --output predictions.csv
```

To refit the analyses and regenerate tables and figures:

```bash
python scripts/run_analysis.py --jobs 6
python scripts/summarise_results.py
python scripts/conditional_intervals.py
python scripts/make_figures.py
```

Intermediate fold models are generated by these commands.

## Shiny

Open `shiny/HBOCpred.Rproj` in RStudio and follow [the short Shiny instructions](shiny/README.md). The interface uses the existing navy header, horizontal filters and a variant-detail panel, with the revised 43,679-record catalogue.

The deployment helper targets the registered `HBOCpred_Shiny_R4_4` application (ID 17838814). Publishing from the connected RStudio account activates https://alaymd.shinyapps.io/HBOCpred_Shiny_R4_4/.
