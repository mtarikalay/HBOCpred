# HBOCpred

Reproducibility materials for the HBOCpred framework for research prioritisation of unresolved germline missense variants in hereditary breast and ovarian cancer.

## Transfer status

The reproducibility package is prepared, but the transfer into this private repository is not yet complete. The repository contents should not yet be treated as the complete analysis release. A verified file inventory will accompany the completed transfer.

A persistent DOI and verified reviewer access remain outstanding.

## Web application

The HBOCpred catalogue viewer is available at https://alaymd.shinyapps.io/hbocpred/.

Model vote states describe computational direction and are separate from ACMG/AMP classifications.
